# libgo

The toolset of library written in Go. It should lightweigh, fast and clean. Supporting your modular framework and direct implementation.

## Features

- [x] Envy - the environment variables loader
- [x] climd - a lightweight command-line interface builder
- [x] foreverwork - typed worker pools and tickers with timeouts, panic recovery and graceful shutdown
- [x] xttp - Fiber v3 routes that generate their own OpenAPI 3.1 YAML/JSON and docs page, with plain handlers
