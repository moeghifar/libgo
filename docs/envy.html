envy

Reflection-based environment variable loader with optional .env support. Struct tags are the whole configuration.

  • Zero config: env, default and required struct tags
  • Types: string, int, uint, bool, float and slices ([]string, []int, comma separated)
  • Nested structs, embedded or named, parsed recursively
  • Optional .env: loaded when present; compiled out with a build tag for production

Install

go get github.com/moeghifar/libgo/pkg/envy

Quick start

package main

import (
	"log"

	"github.com/moeghifar/libgo/pkg/envy"
)

type Config struct {
	AppPort int    `env:"APP_PORT" default:"8080"`
	Debug   bool   `env:"DEBUG" default:"false"`
	APIKey  string `env:"API_KEY" required:"true"`

	// Slices are comma separated in the environment.
	AllowedHosts []string `env:"ALLOWED_HOSTS" default:"localhost"`

	// Nested structs are parsed recursively.
	Database struct {
		DSN string `env:"DB_DSN"`
	}
}

func main() {
	var cfg Config
	// default tags, then .env (if present), then the environment.
	if err := envy.Load(&cfg); err != nil {
		log.Fatalf("config: %v", err)
	}
	log.Printf("listening on :%d", cfg.AppPort)
}

API

SymbolMeaning
func Load(target any) errorFills target from default: tags, then the .env file (if available), then the environment. A required:"true" field left empty is an error.
func Defaults(target any) errorApplies only the default: tags. No .env, no environment, required ignored. Load runs it first.
TagMeaning
env:"NAME"Environment variable to read
default:"v"Value when the variable is unset
required:"true"Load fails if the field ends up empty. A required field that falls back to its default is reported through slog.Default().Warn.

Real usage: one config per command

From example/config.go: a shared Log struct is embedded in each command's config, so migrate runs without server settings and serve without a database.

// Log is shared by every command.
type Log struct {
	Level string `env:"LOG_LEVEL" default:"INFO"`
}

// ServeConfig is the serve command's environment.
type ServeConfig struct {
	Log
	APITokens  []string `env:"API_TOKENS" required:"true"`
	Addr       string   `env:"APP_ADDR" default:"127.0.0.1:8080"`
	RateLimit  int      `env:"RATE_LIMIT" default:"100"`
	Docs       bool     `env:"DOCS_ENABLED" default:"false"`
	TrustProxy bool     `env:"TRUST_PROXY" default:"false"`
}

// MigrateConfig is the migrate command's environment.
type MigrateConfig struct {
	Log
	DSN string `env:"DB_DSN" required:"true"`
}

The matching .env.example:

LOG_LEVEL=INFO
APP_ADDR=127.0.0.1:8080
# Required by serve. Comma-separated; generate with: openssl rand -hex 32
API_TOKENS=
RATE_LIMIT=100
DOCS_ENABLED=false
TRUST_PROXY=false
# Required by migrate only.
DB_DSN=

Build without .env support

By default the package imports github.com/joho/godotenv. In Docker or Kubernetes, where only the real environment matters, drop it (about 600 KB of binary) with a build tag:

go build -o app .                         # development: reads .env
go build -tags libgo_envy_slim -o app .   # production: environment only
